## What it does

`main.py` (Python standard library only) writes a single-line code review
comment to `/output/entry.txt` — a pull request approval carrying quiet
existential dread:

> LGTM. The refactor is clean, the tests pass, and I can already hear the 3am page this code is quietly scheduling.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
